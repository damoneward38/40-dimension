The Core Engine

DIMENSION utilizes a proprietary Spatial CSS Transformation Layer. Unlike traditional WebGL which renders to a flat canvas, Dimension applies 3D matrices directly to DOM elements.

When you hover over a card, our tiltHandler calculates the normalized vector between the mouse position and the element's center. This data is fed into a matrix3d calculation that simulates Z-depth and parallax.

  • ✦ Real-time Raycasting: Simulated via CSS drop-shadows that react to tilt angle.
  • ✦ Asset Persistence: LocalStorage integration for offline session recovery.
  • ✦ Performance: 120FPS rendering via hardware-accelerated transforms.
  • ✦ Zero Latency: Immediate asset wrap on upload.
tiltHandler(event) {
  dx = normalize(event.x, center.x) ← normalized vector to center
  dy = normalize(event.y, center.y)
  el.style.transform = `perspective(1200px)
    rotateX(${-dy * 24}deg) rotateY(${dx * 24}deg)`;
}
